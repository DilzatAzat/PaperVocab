# Start with one word

[中文](GETTING_STARTED.md) · [English](GETTING_STARTED.en.md) · [Back to README](../README.en.md)

The app is free; translation requires your own API. The desktop interface currently uses Chinese. Windows is an early release and Mac is a preview. Complete a translation with a public test word before trying PDF capture.

## 1. Install the desktop app

Choose your platform on the [site](https://dilzat.com/PaperVocab/#download). Use setup.exe for Windows 10/11 x64. On Mac, choose Apple Silicon for M-series chips or Intel for Intel Macs; macOS 11 is the minimum. Move the app into Applications and follow Settings to grant Accessibility access.

Windows is currently unsigned; Mac has no Developer ID signing or notarization. Read the corresponding release notes and checksums before deciding whether to install. [Download notes](DOWNLOAD_TRUST.md) explain the status; do not disable system protection to suppress warnings. If WebView2 is missing, the Windows installer needs internet access to download it.

## 2. Bring your own API

Use a service implementing the **OpenAI Chat Completions compatible protocol**. OpenAI here names the protocol; another compatible provider may work. Not all providers or models have been tested. Native Anthropic Messages and native Gemini APIs cannot be used directly unless the provider offers a separate compatible endpoint.

Get the following from your chosen provider's console. A chat subscription does not necessarily include API access or credits; check the provider's rules.

| Settings field | What to enter | Note |
| --- | --- | --- |
| API Base URL | The provider's API base address, often including `/v1` | Use the API URL rather than a console or chat webpage; use a trusted HTTPS endpoint |
| 模型 / Model | The exact model ID from the console | It must support this protocol and be available to your account |
| API 密钥 / API key | A key generated by the provider | Enter only in the app; do not share in issues, screenshots or chat |
| 目标语言 / Target language | Chinese, English, German, French or Japanese | Chinese is the default; this changes explanations, not the interface |
| 快捷键 / Shortcut | A combination that other apps do not occupy | Initially `Ctrl+Shift+L` / `⌘+Shift+L`; use your saved configuration |

URL format example: `https://api.example.com/v1`. **This is a placeholder, not a real service; do not use it.** The app requests `{Base URL}/chat/completions`. A full `/chat/completions` endpoint is also accepted without adding a duplicate suffix.

Click 保存设置 (Save settings). The key goes into Windows Credential Manager or macOS Keychain. Leaving the key blank preserves an existing key; it does not delete it. No translation credits are included. Consider a small spending limit in the provider's console before making a request.

## 3. Complete one translation

“设置已保存” means settings were saved, not that the API was verified. In the main window's manual input (手动输入单词或短语), enter `robust` and click 收录 (Collect). You should see the word and explanation. If it fails, the original should remain; use the table below and retry. This checks manual capture and the API, not global PDF capture.

Next, open a copyable English PDF, select a word in the reader, press the configured shortcut and release all keys. With no new text, capture should not collect an old clipboard value. Scanned or copy-protected PDFs and some readers may not support capture. PaperVocab has no OCR.

## 4. Revisit and review

收词汇总 (Word library) shows all words by default. Search words or meanings, see the total count, or filter by **first collection date**. Repeated encounters are recorded separately from reviews.

Open 到期复习 (Due reviews), see the English word first, click 查看释义 (Reveal), then select 不认识 / 有点印象 / 认识 (Unknown / Somewhat familiar / Known). The current intervals are 1 / 3 / 7 days. Closing the window keeps the app in the tray/menu bar; quit from that menu and reopen to check saved words remain.

## Troubleshooting

| Symptom | Next step |
| --- | --- |
| No new copyable text | Check that the reader can manually copy the selection and use the registered shortcut. Scanned text needs the reader's own OCR; PaperVocab has none |
| Shortcut registration failed | Choose an unused combination, save and check the error clears. Manual input success does not verify the shortcut |
| 401 / 403 | Check your key, permissions and provider requirements; never post the key |
| 404 / HTML or non-JSON response | Check the API URL, path and protocol in the provider's docs; you may have entered a webpage |
| 429 | Check rate limits or credits, wait and retry sparingly |
| Timeout / 5xx | Check the network, endpoint and service status; retry later. The saved original remains |
| Explanation in the previous language | Translate the word again after switching; one latest target-language explanation is stored per word |
| App remains after closing | Expected tray behavior; choose Quit from the tray/menu bar |
