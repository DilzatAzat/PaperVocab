# 从第一个词开始

[中文](GETTING_STARTED.md) · [English](GETTING_STARTED.en.md) · [回到 README](../README.md)

PaperVocab 软件免费；翻译需要自己配置 API。当前桌面界面为中文，Windows 为早期版，Mac 为测试版。先用公开测试词完成一次翻译，再尝试论文选区。

## 1. 安装桌面软件

在[官网](https://dilzat.com/PaperVocab/#download)选择平台。Windows 10/11 x64 使用 setup.exe；Mac 的 M 系列选择 Apple Silicon，Intel 选择 Intel Mac，最低 macOS 11。Mac 将应用拖入“应用程序”，按照软件设置指引授权辅助功能。

当前 Windows 未签名，Mac 无 Developer ID 签名和公证；查看对应 Release 的说明和校验文件后自行决定是否安装。[下载提示说明](DOWNLOAD_TRUST.md)解释当前状态，不需要为此关闭系统安全保护。Windows 缺少 WebView2 时需联网下载运行时。

## 2. 准备自己的 API

你需要一个支持 **OpenAI Chat Completions 兼容协议**的服务。OpenAI 在这里是接口协议名称，服务商不必是 OpenAI；并非所有服务或模型已测试兼容。原生 Anthropic Messages、Gemini 原生 API 不能直接填入，除非服务商另提供兼容端点。

到你选择的服务商控制台获取以下信息。网页聊天订阅不必然包含 API 权限或额度；以服务商规则为准。

| 设置字段 | 填写内容 | 注意 |
| --- | --- | --- |
| API Base URL | 服务商提供的 API 根地址，通常包含 `/v1` | 填 API 地址，而非控制台/聊天网页地址；推荐使用可信 HTTPS |
| 模型 | 控制台显示的准确模型 ID | 必须是此账号可调用且支持上述接口的模型 |
| API 密钥 | 服务商生成的密钥 | 只在软件设置中填写，不发到 Issue、截图或聊天 |
| 目标语言 | 中文、English、Deutsch、Français 或日本語 | 默认中文；只改变释义语言 |
| 快捷键 | 选择未被其他应用占用的组合键 | 初始默认 `Ctrl+Shift+L` / `⌘+Shift+L`；以实际保存的配置为准 |

地址格式示意：`https://api.example.com/v1`。**这是占位示例，不是真实服务，不能直接使用。** 软件会请求 `{Base URL}/chat/completions`；若你填的是完整 `/chat/completions` 端点，软件也会使用它，不重复添加后缀。

保存后密钥进入 Windows 凭据管理器或 macOS Keychain。留空密钥表示保留已保存密钥，并不是删除密钥。软件不附送翻译额度；首次请求前建议在服务商控制台设置较小预算。

## 3. 完成一次翻译

“设置已保存”仅代表配置保存，不证明网络或密钥有效。先在主窗口“手动输入单词或短语”中输入 `robust` 并收录。成功后应看到原词和释义；遇到失败原词应仍在，按下面的表排查后点击重试。这一步只检查手动收词和 API，不能替代 PDF 全局取词验收。

然后打开可复制的英文 PDF，在阅读器中选词，按实际配置的快捷键并松开所有组合键。没有新文本时不应收旧剪贴板内容。扫描 PDF、禁止复制的 PDF 和部分阅读器可能不能取词；当前没有 OCR。

## 4. 找回与复习

“收词汇总”默认显示全部词，可搜索单词或释义、查看词库总数；日期筛选是**首次收录日期**。同词再次遇见追加遇见记录，重复遇见不算复习。

进入“到期复习”，先看英文，主动点击“查看释义”，再选择“不认识 / 有点印象 / 认识”。当前间隔规则分别为 1 / 3 / 7 天。关闭主窗口后应用继续在托盘/菜单栏运行；从该图标菜单退出，再打开可检查已保存单词是否仍在。

## 遇到问题

| 现象 | 下一步 |
| --- | --- |
| 没有新的可复制文本 | 先检查阅读器能否手动复制选区；使用设置中实际注册的快捷键。扫描文本需要阅读器自己的 OCR，PaperVocab 没有 OCR |
| 快捷键注册失败 | 更换未占用的组合键，保存后确认错误消失；不要把手动输入成功当作快捷键正常 |
| 401 / 403 | 检查密钥、权限和服务商要求；不要公开密钥来求助 |
| 404 / 响应是 HTML 或非 JSON | Base URL 可能填了网页地址、接口路径错误或协议不兼容；核对服务商 API 文档 |
| 429 | 查看服务商的限流/额度说明；等待后有限重试，不连续刷请求 |
| 网络超时 / 5xx | 检查网络、地址和服务状态；稍后重试，已保存原词保留 |
| 有旧语言释义 | 修改目标语言后在词表选择重新翻译；当前每个词只保留最近一种释义 |
| 关闭后软件仍在 | 这是托盘常驻行为；通过托盘/菜单栏菜单退出 |
