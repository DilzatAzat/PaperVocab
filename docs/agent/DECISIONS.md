# 关键决策

## 2026-09-27：独立 Tauri 项目

PaperVocab 建在独立目录，不复用博客的 Jekyll 或部署设置。产品边界、数据模型和发布目标完全不同。

## 2026-09-27：模拟复制取词

快捷键触发 Ctrl+C，并比较剪贴板序号；只在序号变化且读取到新文本时收录。这样不持续读取剪贴板历史，也不以空文本误收录旧内容。图片等非文本内容不会被覆盖写回。

## 2026-09-27：密钥使用 Windows 凭据管理器

翻译请求由 Rust 后端发出。数据库只保存 API 地址、模型、领域和快捷键，不保存密钥。

## 2026-09-27：简单确定复习间隔

不认识/有点印象/认识对应 1/3/7 天。每次复习写入独立事件，重复遇见不会冒充复习。
