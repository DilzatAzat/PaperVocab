# 关键决策

## 2026-09-27：独立 Tauri 项目

PaperVocab 建在独立目录，不复用博客的 Jekyll 或部署设置。产品边界、数据模型和发布目标完全不同。

## 2026-09-27：模拟复制取词

快捷键触发 Ctrl+C，并比较剪贴板序号；只在序号变化且读取到新文本时收录。这样不持续读取剪贴板历史，也不以空文本误收录旧内容。成功取词后仅在序号未再次变化时尽量恢复原有文字或图片；自定义格式和并发复制仍列为 Windows 实测项。

## 2026-09-27：密钥使用 Windows 凭据管理器

翻译请求由 Rust 后端发出。数据库只保存 API 地址、模型、目标语言和快捷键，不保存密钥。

## 2026-09-27：简单确定复习间隔

不认识/有点印象/认识对应 1/3/7 天。每次复习写入独立事件，重复遇见不会冒充复习。

## 2026-09-29：同仓库托管主页，安装包由 Release 提供

公开仓库使用 GitHub Pages 托管 `site/`，不另建仓库。安装包留在 GitHub Releases，不加入 Git 历史或 Pages。主页查询最新 Release 的真实 NSIS 资产；没有资产时显示待发布状态。发布工作流校验 tag 与三个应用版本一致。

## 2026-09-29：目标语言替代固定领域

英文论文是固定源文本；释义目标语言默认中文，可选 English、Deutsch、Français、日本語。切换目标语言后已有旧语言释义标记为需要重新翻译，单词仍只保留最近一种语言的释义，避免在第一版引入多语言版本管理。

## 2026-09-30：翻译请求使用 generation 隔离

同一个单词可能在网络请求尚未返回时再次触发翻译。每条请求递增 `translation_generation`，成功或失败写回必须同时匹配单词、目标语言、generation 和可写状态；旧请求不能覆盖后发请求。该字段在旧数据库启动时自动迁移，备份不导出内部 generation。

## 2026-09-29：宣传页区分当前能力与产品方向

宣传页以论文阅读、翻译和复习为主线；开源入口保留在页脚，不作为主要卖点。当前支持的 API 协议和目标语言明确写出；手机复习、跨设备接续及更多 API 协议只作为后续方向，避免提前宣称已实现。

## 2026-09-30：收词汇总替代双页面

“今日收词”和“全部单词”使用同一单词列表能力，拆成两个入口会重复表达。第一版统一为“收词汇总”：默认展示全部词，日期筛选留空表示不限制日期，筛选结果数与本地词库总数分开显示。

## 2026-09-30：桌面主窗使用自绘标题栏和轻量玻璃层

主窗口关闭仍由 Tauri close handler 隐藏到托盘；自绘标题栏只负责最小化、最大化和关闭操作。玻璃材质限定在侧栏、工具区和列表等界面层，使用透明度、细边框和模糊建立层次，避免引入新的 UI 框架。
