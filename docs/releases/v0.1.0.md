# PaperVocab v0.1.0

PaperVocab 首个公开版本，面向 Windows 10/11 x64。

## 下载与使用

1. 下载下方的 `PaperVocab_0.1.0_x64-setup.exe`，双击完成安装。
2. 打开 PaperVocab，在“设置”填写自己的 OpenAI Chat Completions 兼容 API 地址、模型及密钥。软件不附带翻译 API 或免费额度。
3. 在可复制英文文本的 PDF 或浏览器中选词，按默认快捷键 `Ctrl+Shift+L`。原词先保存，再请求释义。
4. 在“收词汇总”查看、搜索和按首次收录日期筛选；在“到期复习”完成复习。

关闭主窗口会驻留托盘。要完全退出，请右键托盘图标并选择退出。

安装版无需 Node.js、Rust 或开发终端。若系统缺少 WebView2，安装程序会下载运行时，需要联网。

## 包含功能

- 全局快捷键、取词浮窗、单实例与托盘。
- 本地 SQLite 单词本，记录重复遇见，支持搜索和日期筛选。
- 中文、英语、德语、法语、日语目标释义，翻译失败可重试。
- 三档基础复习，密钥保存在 Windows 凭据管理器。
- 新艺术 P 图标、玻璃风格界面及统一中文日期控件。

## 当前限制

- 安装包尚未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。
- 当前只接入 OpenAI Chat Completions 兼容协议；原生 Anthropic/Gemini 协议暂不支持。
- 不支持 OCR 或扫描 PDF 取词；剪贴板自定义格式可能无法完整恢复。
- 每个单词保留最近一次目标语言释义；切换语言后需要重新翻译。
- 完整 JSON 导入导出界面尚未提供。
- 已完成本机安装/启动及部分桌面交互检查、自动化测试和 Windows 构建；真实 PDF、多阅读器、焦点与剪贴板并发保护、完整卸载流程仍待进一步验收。

单词保存在本机；选中文本会发送至你配置的翻译 API。发布的安装包不包含个人词库或 API 密钥。

## English

The first public PaperVocab release for Windows 10/11 x64.

Download `PaperVocab_0.1.0_x64-setup.exe`, run the installer, and open PaperVocab. Configure your own OpenAI Chat Completions compatible API URL, model, and key in Settings. No translation service or API credits are included. Select copyable English text in a PDF or browser and press `Ctrl+Shift+L`; the word is saved before translation. Use the word library and due reviews to revisit your vocabulary.

Closing the main window keeps the app in the tray; right-click its tray icon to quit. Node.js and Rust are not required. The installer downloads WebView2 if it is missing, which requires an internet connection.

The installer is currently unsigned. Windows may show an unknown publisher or SmartScreen prompt. OCR/scanned PDFs and native Anthropic/Gemini protocols are unsupported. Clipboard custom formats may not be fully restored; each word stores one latest target-language explanation. The JSON import/export UI is still incomplete. Real PDF, multiple-reader, focus, clipboard concurrency, and full uninstall checks remain pending; this release has passed automated checks, Windows builds, and partial local desktop checks.

Vocabulary is stored locally; selected text is sent to your configured translation API. The installer contains no personal database or API keys. `SHA256SUMS.txt` provides a checksum for the installer.
