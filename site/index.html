你可能想问。

软件和翻译都免费吗？需要注册吗？

PaperVocab 可免费下载和使用，无需注册 PaperVocab 账号。翻译需要你自己的 API，服务商可能收取费用，也可能要求注册；软件不附赠翻译额度。

只能用 OpenAI 吗？

“OpenAI Chat Completions”在这里指 API 协议，不是限定服务品牌。兼容这个协议的服务可以配置，但并非所有服务都经过逐一验证；其他原生协议目前未实现。

扫描 PDF 可以用吗？

当前取词依赖源应用能复制选中文本。扫描图片、复制受限的 PDF 或部分阅读器可能无法取词；第一版不提供 OCR，可以手动输入或粘贴。

没有网络时还能做什么？

已有词库和复习记录保存在本地，可以离线查看。新的原词会先保存，在线翻译失败后可以重试；调用外部 API 需要网络。

我的密钥、单词和原句放在哪里？

词库保存在本机 SQLite；密钥保存在 Windows 凭据管理器或 macOS Keychain。翻译时，所选文本和你补充的原句会发送给配置的 API 服务。PaperVocab 不上传剪贴板历史，服务商的数据政策需自行核对。

为什么下载或启动时有安全提示？

已核对的 v0.1.0 Windows 安装包未签名，可能出现 Edge 少下载或 SmartScreen 提示；Mac 测试版未做 Developer ID 签名与公证。请核对官方 Release 和校验文件。不能通过关闭系统安全保护来代替签名与验收。

网页能切英文，软件也是双语吗？

目前 Windows 与 Mac 桌面界面为中文。网页和使用文档提供中英文；释义的目标语言可选中文、英语、德语、法语或日语。同一个词当前只保留最近目标语言的释义。
