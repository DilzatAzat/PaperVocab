MADE FOR RESEARCH READING

查词、翻译，继续读。

选词即查，释义和遇见记录随手留存。原文面向英文论文，目标语言可选择中文、英语、德语、法语或日语。

↗自选翻译服务

目前支持兼容 OpenAI Chat Completions 协议的 API；密钥保存在 Windows 凭据管理器。

⌁选择目标语言

当前可选中文、英语、德语、法语和日语；默认目标语言为中文。

✓统一收词与复习

收词汇总支持搜索、首次收录日期筛选和总数查看；重复遇见不会被误算为复习。

READY WHEN YOU ARE

开始更顺畅的论文阅读。

下载安装包 → 运行安装 → 配置自己的 Chat Completions 兼容 API，即可开始使用。首次翻译需要你自己的 API 地址、模型与密钥；软件不内置翻译服务。
